# Money Manager App

A project for my Object-Oriented Programming course (Fall 2025). I implemented all backend logic and designed the class and architecture diagrams. The frontend user interface was provided by my professor.

## Description

The goal of this project was to build the foundation of a money management system. The system allows users to record and track their personal finances over time. Users can enter details such as income, expenses, budgets, debts, and sinking funds. The system provides a structured way to organize these entries and monitor overall financial health, including how money is earned, spent, and allocated.

3. In the terminal click the http://127.0.0.1:5000 link to open the app in your browser.
